# 项目进度

## 目标与范围

公开 GitHub 仓库每天通过 GitHub Actions 抓取 GitHub Trending 并推送到飞书；每周一附加 This week 榜单，每月 1 日附加 This month 榜单。日榜、周榜、月榜合并为同一条消息。

不包含：WorkBuddy 签到、账号 Token、持久化榜单数据库或本地常驻服务。
