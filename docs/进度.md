## 验收方式

1. 确认仓库为 Public，文件包含 .github/workflows/daily.yml。
2. 确认 Actions Secret 列表中存在 FEISHU_WEBHOOK（只确认名称，不查看或记录值）。
3. 从 Actions 手动运行一次，检查工作流日志显示推送成功并在飞书群收到标题为“GitHub热榜”的消息。
4. 周一及每月 1 日检查消息是否附加对应周期榜单。
